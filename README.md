# 초축 리그 MMR 시스템

초능력축구 리그의 MMR·기록 관리 웹 시스템. 스펙은 `PRD.md` 참고.

## 실행 (의존성 설치 불필요 — Node.js 22+ 만 있으면 됨)

```
node server/index.js
```

→ http://localhost:3300 접속. 또는 `시작.bat` 더블클릭.

- 포트 변경: 환경변수 `PORT`
- 데이터: `data/league.db` (SQLite 파일 하나 — 백업 = 파일 복사)
- DB 초기화: 서버 끄고 `data` 폴더 삭제 후 재시작 (티어 10단계·선수 45명 자동 시드)

## 관리자

우측 상단 "관리자" → 기본 비밀번호 `admin1234`
(변경: `data/league.db`의 config 테이블 `admin_password` 값 수정)

- **경기 입력**: 선수 4명씩 + 스탯 입력 → 저장 즉시 MMR·수비왕·언더독 자동 계산.
  급여 합이 상한(90)을 넘으면 실시간 경고, 아마추어/프로 자격 위반도 저장 전 경고
- **경기 목록**: 수정/삭제 — 과거 경기를 고치면 이후 전체 MMR 자동 재계산
- **선수 관리**: 티어·배치 티어·팀 변경, 신규 선수 추가
- **팀 · 로스터**: 팀 생성/이름 변경/삭제, 감독·코치 지정, 선수 배정 (총 9명 / S~A- 4명 / B+~C- 7명 제한 표시).
  경기 기록이 있는 팀은 삭제 불가(경기 먼저 삭제), 팀 삭제 시 소속 선수는 미배정으로 복귀

## MMR 규칙 (구현 완료 — M1)

- 승 +30 / 패 -30 / 무 0
- 언더독(4인 MMR 합 500p 이상 차): 약팀 +40/-20, 강팀 +20/-40
- 모든 규칙 상수는 config 테이블에서 변경 가능

## 남은 단계

- **M2**: 월요일 정기 갱신(공식 MMR·승급/강등·휴면 강등), 급여 승격 보상, 아마추어 팀 배정 도우미
- **M3**: 스킬 소유·피어리스룰 검증, 스킬 통계, 엑셀 임포트, 구 Elo 레이팅 병행 표시

## 구조

```
server/index.js   HTTP 서버 + API (node:http, 외부 패키지 없음)
server/db.js      스키마·시드 (node:sqlite)
server/mmr.js     MMR 엔진 (전체 재계산 방식)
public/           프론트엔드 (바닐라 JS SPA)
data/league.db    데이터 (자동 생성)
```
